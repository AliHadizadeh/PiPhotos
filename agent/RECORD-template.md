# Record: <task, e.g. "Backup set up">

Copy this file into the person's project folder as `RECORD.md`, or append a new entry to an existing one. One entry per task. Fill every heading. Write numbers, not adjectives.

## When and what

- Date and time, with the time zone.
- Chapter and runbook used.
- Versions: Immich, Raspberry Pi OS kernel, the tools' commit or date.

## Site values used

Device names by id, mount points, users, where the keys live. No secrets.

## What was done

Numbered, in the order it happened, with the commands or the scripts and their main arguments.

## Results

The numbers from the checks: counts, sizes, durations, speeds, error counts. Paste the last lines of the relevant log.

## What failed and what fixed it

Every failure, even the ones that were fixed, with the cause.

## Open

What was skipped, what is not verified, what the person still has to decide.
